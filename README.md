# Road Object Detection in Foggy Complex Scenes

## Project Overview

This project explores road-object detection under foggy and low-visibility conditions using computer vision and deep learning.

It is a reconstructed learning implementation based on my original B.Tech major project topic, **Road Object Detection in Foggy Complex Scenes Based on Improved YOLOv10**.

## Objectives

* Explore object detection for vehicles and pedestrians.
* Understand how fog affects visibility in road images.
* Experiment with image enhancement using OpenCV.
* Explore how YOLO-based object detection can support road-safety applications.

## Technologies

* Python
* YOLO object detection
* OpenCV
* Flask (planned web interface)

## Methodology

1. Load a road image.
2. Optionally apply image enhancement.
3. Run object detection using a compatible YOLO model.
4. Visualize and save the detection results.
5. Compare results and document limitations.

## Current Status

This repository is being reconstructed for learning and portfolio purposes. The original project files are unavailable. Model improvements and performance metrics will only be reported after implementation and testing.

## Future Improvements

* Evaluate the model on permitted foggy-road datasets.
* Compare detection results with and without image enhancement.
* Add a Flask interface for uploading images.
* Document evaluation metrics and limitations.

## Learning Outcomes

This project helps demonstrate concepts in computer vision, Python programming, image processing, and object detection.
